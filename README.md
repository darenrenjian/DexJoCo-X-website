# DexJoCo-X project website

Project page: https://darenrenjian.github.io/DexJoCo-X-website/

**DexJoCo-X: Benchmarking Action Representations for Multi-Hand Dexterous Manipulation**

Xiangwei Jiang, Yao Mu, Lixin Duan, and Wen Li (corresponding author).

This repository contains the static project website, paper PDF, original schematic illustrations rendered for the web, and overview video. The arXiv link will be added when the preprint is available. Benchmark code and dataset availability are shown on the website independently.

To preview locally:

```bash
python3 -m http.server 8765
```

Deployment uses GitHub Pages from the root of the `main` branch. The heading font is EB Garamond; its font file and OFL license are included in `assets/fonts/`.
